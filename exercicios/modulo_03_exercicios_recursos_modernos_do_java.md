# Exercícios Práticos — Módulo 03: Java Moderno: Novas Features

## Objetivo

Consolidar os conceitos do módulo em uma implementação executável e documentada.

## Exercício 1 — Implementação incremental

Implemente uma funcionalidade de biblioteca que combine os conceitos das aulas. Registre os requisitos, implemente uma versão mínima e valide um cenário de sucesso e um de falha.

## Exercício 2 — Evolução da solução

Refatore ou amplie a implementação com uma melhoria de qualidade adequada ao tema: validação, testes, tratamento de erros, documentação ou desempenho.

## Entrega

Inclua código, instruções de execução, exemplos de uso e uma seção “O que aprendi”.
