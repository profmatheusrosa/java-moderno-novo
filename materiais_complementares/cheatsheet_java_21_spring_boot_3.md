# Cheatsheet — Java 21 e Spring Boot 3

| Recurso | Exemplo |
|---|---|
| Compilar | `javac Classe.java` |
| Executar | `java Classe` |
| Record | `record Livro(String titulo) {}` |
| Stream | `itens.stream().filter(...).toList()` |
| Virtual Thread | `Thread.startVirtualThread(tarefa)` |
| Controller | `@RestController` |
| Rota GET | `@GetMapping("/livros")` |
| Validação | `@Valid @RequestBody` |
