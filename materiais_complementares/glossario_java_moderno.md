# Glossário — Java Moderno

| Termo | Definição |
|---|---|
| API | Contrato para consumo de operações e tipos. |
| Bean | Objeto gerenciado pelo container Spring. |
| DTO | Objeto de transporte de dados entre camadas. |
| JPA | Especificação Java para persistência objeto-relacional. |
| REST | Estilo arquitetural baseado em recursos e HTTP. |
| Stream | Pipeline declarativo para processar dados. |
| Virtual Thread | Thread leve gerenciada pela JVM no Java 21+. |
